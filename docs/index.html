Tnux

a cmux fork for running a lot of agents at once

Tnux is cmux, the macOS terminal built around Ghostty, with a stack of hacks for one workload: thirty-odd panes across a few workspaces, most of them hosting a Claude Code session, and never losing track of which is which.

It started as "tabcaller": color the tabs so a wall of identical terminals becomes readable. It grew into pane identity, aging, grid layouts, a restart that puts every session back where it was, and menus that answer "what was I doing, and which agent needs me now".

What it adds

Pane identity

Every pane gets a stable pastel color and a folder — title chip. The focused pane's header strip takes the color with black chrome; its terminal goes a shade darker.

Aging

Each chip is a gauge: its color fill shrinks from the right since you last acted in the pane, full under ten minutes and empty at two weeks. Nothing moves; the fresh ones just pop.

Restart that restores

Fixed the bug where panes swapped sessions and folders after a relaunch (stale tty attribution). Rolling layout backups every five minutes, with a restore menu.

Grid layouts

Arrange menu, ⌘⌃1…9 rows, ⌘⌥1…9 columns, or cmux arrange-panes --rows 3. Every surface keeps its pane; dividers equalize.

Panes and History menus

Every pane across every window with its agent status (needs input, running, idle), and a 30-deep focus history listed pane first.

Workspace colors

Give a workspace a color and it shows as a dot before the name and as the selected highlight.

What it's for

  • Running many long-lived coding agents in parallel without losing the thread of which project each one belongs to.
  • Coming back after a crash or reboot to the exact layout, folders, and resumed sessions you left.
  • Triage: see at a glance which panes are waiting for you, which are working, and which have gone cold.
  • Reshaping a crowded window into rows or columns in one keystroke instead of dragging dividers.

Get it
